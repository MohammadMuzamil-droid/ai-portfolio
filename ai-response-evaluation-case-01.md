# AI Response Evaluation Case 01

## Scenario

**User Prompt:**

What is over-browsing in web search evaluation?

**AI Response:**

Over-browsing means performing too many searches when one or two searches would have been enough. Therefore, if an evaluator performs several relevant searches to make sure the answer is accurate, that is considered over-browsing because the evaluator should stop searching as soon as possible.

## Evaluation

### Overall Assessment

The response is partially correct but contains an important conceptual error.

### Strengths

- It correctly recognizes that over-browsing is related to unnecessary or excessive searching.
- It attempts to distinguish useful searches from unnecessary searches.
- The explanation is concise and directly related to the question.

### Issues

The main problem is the claim that several relevant searches automatically constitute over-browsing.

Over-browsing is not determined simply by the number of searches. The important factor is whether additional browsing provides meaningful value relative to its cost.

If multiple searches are necessary to resolve uncertainty, verify conflicting information, or answer different aspects of the user's request, those searches may still be relevant and justified.

Therefore, the response uses an overly rigid rule: "one or two searches should have been enough."

### Reasoning

A better evaluation should consider:

1. Whether the searches are relevant to the user's information need.
2. Whether additional searches reduce meaningful uncertainty.
3. Whether the information obtained is useful for producing a reliable answer.
4. Whether the additional browsing has become redundant or provides little additional value.
5. The cost of continued browsing compared with the benefit it provides.

The number of searches alone is not sufficient to determine whether browsing is excessive.

## Improved Response

Over-browsing generally refers to continuing to browse beyond what is reasonably necessary to answer the user's question reliably.

It is not defined simply by the number of searches. Multiple searches can be justified when they address different aspects of the question, verify important information, or resolve uncertainty.

Browsing becomes excessive when additional searches are largely redundant, provide little meaningful new information, or add cost without a corresponding improvement in the answer.

## Skills Demonstrated

- Identifying conceptual inaccuracies
- Distinguishing rigid rules from contextual evaluation
- Evaluating reasoning quality
- Identifying unsupported generalizations
- Comparing alternative interpretations
- Evidence-based reasoning
- Clear written analysis
